# 💰 Splitz - Automatización de Porcentajes e Inteligencia Financiera

¡Toma el control total de tu dinero! **Splitz** es una aplicación web personal diseñada para automatizar la distribución de ingresos, potenciar la inteligencia financiera y optimizar el control de gastos. 

---

## 🚀 Estado Actual del Proyecto

Actualmente, la aplicación se enfoca en la **gestión y distribución inteligente de ingresos a través de porcentajes**. El sistema recibe un monto base en pesos (COP) y calcula automáticamente la distribución idónea según la estrategia financiera configurada.

* **Core Lógico:** Procesamiento y transformación de datos financieros en tiempo real.
* **Interfaz Limpia:** Maquetación moderna, responsive (Mobile-First) y optimizada visualmente con una paleta basada en tonos verdes de éxito financiero.
* **Sin Persistencia Aún:** En esta fase inicial, la aplicación opera en memoria (inputs y lógica de negocio), asegurando un flujo rápido y desacoplado antes de la integración con base de datos.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python con Django (Arquitectura robusta y escalable).
* **Frontend:** HTML5, CSS3 nativo (Variables globales, Media Queries, diseño 100% responsive).
* **Buenas Prácticas:** Principios SOLID, modularización de estilos y Gitflow.
